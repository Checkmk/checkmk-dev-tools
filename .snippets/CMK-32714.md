## Only query the minimal amount of Jenkins queue data necessary
<!--
type: bugfix
scope: all
affected: all
-->

With this change only a minimal amount of data of Jenkins queue data is queried.

The queue request depth is reduced from `2` to `1` resulting in 36kB instead of 7.5MB data provided by Jenkins. This amount of data is requested for every job checking or awaiting a job to start building.

Furthermore no queue items are requested anymore as the queue_info already contains all queue items with all their required data. This reduces the number of calls towards jenkins.tld/queue from N+1 with N as the number of elements in the queue to 1.
