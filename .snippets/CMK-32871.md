## Extend logging while identifying a matching build
<!--
type: feature
scope: all
affected: all
-->

The logging output on `INFO` level is extended while identifying a matching build. Log messages are now printed if:
- with InfluxDB enabled:
    - no matching InfluxDB entry was found
    - a Jenkins API query for queued items is started
    - no matching Jenkins queue item was found
    - no match at all was found, causing a new build
- without InfluxDB enabled:
    - matching existing builds via Jenkins API are queried
    - no matching existing build was found via Jenkins API
    - matching non-finished builds via Jenkins API are queried
    - no matching non-finished build was found via Jenkins API
    - a Jenkins API query for queued items is started
    - no matching Jenkins queue item was found
    - no match at all was found, causing a new build
